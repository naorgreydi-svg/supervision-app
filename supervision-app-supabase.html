התקנה ראשונית - Supabase

📋 הוראות התקנה (5 דקות):

  1. צור חשבון Supabase:
    גש ל-https://supabase.com
    לחץ "Start your project" והתחבר עם GitHub/Google
  2. צור פרויקט חדש:
    לחץ "New Project"
    שם: supervision-system
    סיסמת Database: שמור אותה! (תצטרך מאוחר יותר)
    Region: בחר West Asia (הכי קרוב לישראל)
    לחץ "Create new project" והמתן כדקה
  3. קבל את ה-URL וה-API Key:
    מהתפריט הצדדי: Settings → API
    העתק את:
    • Project URL (https://xxx.supabase.co)
    • anon public key (eyJh...)
  4. הדבק למטה והתחל לעבוד!
💡 טיפ: שמור את הפרטים האלה במקום בטוח. תצטרך אותן רק פעם אחת.
